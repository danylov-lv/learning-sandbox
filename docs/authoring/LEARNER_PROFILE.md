Study API engineering, developer tooling, Rust, TypeScript, machine learning, and AI alongside data engineering to broaden practical skills and stay competitive in the job market.

## Calibrate new modules

- Start with the learner's current topic-specific experience and reason for requesting the module. Prefer newer self-reported experience over the baseline above. Confirm any missing prerequisite that would materially affect the exercise design.
- Reuse marketplace or scraped-data scenarios where they fit the skill. Build on an existing module when it already teaches a prerequisite. State what the new module adds and name any prior work or running service required to start it.
- Choose a practical outcome the learner can verify, such as a correct result under late data, a diagnostic backed by a query plan, or a trade-off supported by local measurements. Cover beginner techniques where hands-on experience is limited, with a short practice-first ramp.
- Fit local exercises to Windows, Docker, 32 GB RAM, and 8 GB of GPU VRAM. The learner uses both native Windows tooling and containers, with PostgreSQL in Docker. Use an honest local approximation for larger systems and identify which production behaviors it can exercise.
